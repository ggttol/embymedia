# Agent Note: Canonical Series binding owns missing-episode completion

Status: implemented

[English](2026-08-31-canonical-series-missing-episode-binding.md) | 中文

## Problem

115 文件或 STRM 路径可见只能证明存储发现，不能证明 Emby 将请求的缺集归入预期 Series。相似标题、重复 TMDB 身份与替代根目录可能让原 Series 仍不完整。受保护分享的临时访问码不能成为持久完成状态的权威。

## Decision

`series_auto_fill` 仅限名称完全匹配的 `电视剧追更`、`综艺追更` 媒体库及其同名 115 CID 映射。它要求唯一 TMDB 绑定 Series 与准确的 115 直接子目录，盘点已播出且有编号的缺集，为每个 Series 检索有界的 1–30 个候选，不按索引健康标记筛选，并在最多 20 层深度内递归检查最多 10,000 个条目。只有具有明确匹配集号的受支持视频叶文件才能证明覆盖；上级标题与整包范围不能虚构缺失叶文件。候选标签及每个视频的上级路径必须独立符合 Series 身份。

普通转存将准确选中的叶文件 ID 接收到既有 Series CID，等待 CloudDrive 可见，同步 STRM，扫描 Emby，并验证原 Series 拥有请求的剧集。仍有缺集时，检查失败保留每个资源 ID 及原因，而不是用最后一个被拒绝分享解释整个 Series。成功检查但没有合适剧集的分享仍属于普通资源缺口。最终 Emby 身份与缺集验证不依赖重新打开受保护分享或保留访问码。

启用 `replace_completed_pack` 与浏览器拥有的危险操作开关后，仅当视频叶文件覆盖全部预期已播剧集时，任务才能暂存一个独立根。它先验证完整替代 Series，再删除旧 Emby 条目、回收旧 115 根、移除其受限 STRM 根并再次扫描。失败尝试只移除经过验证且属于该操作的暂存内容；切换状态不确定时要求恢复处理，不删除任何未经验证的副本。

Drive 服务将分享快照请求串行化至响应关闭。`share_snapshot_interval_ms` 默认在上一响应与下一请求之间间隔 1000 毫秒；零取消延迟但保留串行化。取消会停止等待。带类型的 HTTP 405/429 错误停止后续候选及 Series，并保留部分证据；成功响应内类似状态码的文本不属于 HTTP 失败。不完整快照不能授权转存，节流也不保证 provider 接受请求。

Emby 原生删除要求已启用管理员的获授权设备会话与每个条目的 `CanDelete` 权限；浏览器代理身份、Agent token 和应用 API key 均不能替代。确认内容包含生成 STRM 路径与原视频路径。网关串行化媒体修改，检查准确的原生 `DeleteInfo` 路径，并仅在原生删除成功后回收重新验证身份的 115 原文件。回收失败保留为经审计的部分完成结果，不回滚或自动重放。默认文件系统 ACL 保留 Emby 对生成目录的共享写入权限，不削弱服务 umask。

## Testing

独立队列测试通过协议兼容 fixture 覆盖 Emby 缺集发现、资源搜索、115 递归检查、精确接收、CloudDrive 可见性、STRM 生成、扫描完成与扫描后验证。候选回归要求可读分享即使索引标记无效或缺失仍可参与检查，隔离被拒绝分享，并保留每个未解决的检查失败。替换测试要求完整覆盖及危险操作开关，并强制先验证再删除旧根。其他场景拒绝不合格媒体库、重复 TMDB Series、未来或无编号剧集，以及把分辨率数字误认为集号的情况。

独立删除测试覆盖管理员／设备授权、应用 key 拒绝、原路径确认、源身份漂移、原生失败及部分回收。历史真实验收通过隔离的两集 fixture 确认单集删除保留相邻集，以及 Series 删除回收原文件；这不授权在生产媒体上重复破坏性测试。

## Alternatives considered

**把可见性视为完成。** 第二根目录或错误归属的剧集可以可见，而预期 Series 仍保留缺集。当前 Series 身份与剧集归属定义成功。

**仅按名称定位目标或删除重复项。** 名称可能漂移或冲突。准确的 Emby 身份、存储 ID、路径关系与唯一性检查避免有歧义的目标定位。

**验证替代副本前删除旧根。** 已转存整包可能不完整，或被解析为错误 Series。移除旧副本前必须验证每个预期已播剧集。

**为最终验证重新打开受保护分享。** 分享可用性与访问码不是后置条件。持久的 Emby、TMDB、剧集与放置事实无需恢复凭据即可观测。

**信任索引健康标记。** 有效标记可能对应错误或缺失的访问码，无效或未检查标记也可能隐藏可读分享。索引元数据不能授权转存，也不能否决实时检查。

## Consequences

完成意味着预期 Series 拥有请求的剧集，或经过验证的完整替代副本在删除旧根后成为唯一的同 TMDB 保留项。身份有歧义、资源证据不完整及外部副作用不确定时均拒绝继续。明确启用自动替换会增加无人值守删除风险，但受到任务选项、浏览器开关、完整覆盖与有序验证的约束。普通文件转存不承诺完成缺集修复。
