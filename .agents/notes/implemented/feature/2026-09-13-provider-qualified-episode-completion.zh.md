# Agent Note: Provider-qualified automatic episode completion

Status: implemented

## Problem

自动补集原来只能检查并选择性转存 115 分享。夸克到 115 导入器只能把整个已保存分享移动到 `/emby/_待整理`；直接连接会复制无关文件，并允许目标在重启后发生漂移。

## Decision

自动补集分别搜索 115 与夸克，检查每个实时分享树，并保留现有标题、年份、TMDB、季和集号证据规则。预检不执行 provider 写操作。同一集有多个可用资源时显示为冲突；操作者必须选择带 provider 的资源后才能转存。

115 叶子继续通过选择性分享转存处理。夸克叶子创建持久子任务，其中仅包含选中的源 ID 与预期集号。在执行任何夸克转存前，子任务重新验证已配置的夸克目标、当前 `c115_cid_map`、固定 115 账号、Emby 媒体库、规范 Series 路径与 TMDB 身份，以及 115 中准确的直接子目录。该绑定及全部传输检查点在重启和重试期间不可变。公开任务请求不能提交这些内部绑定字段。

绑定的子任务把文件直接上传到已验证的 Series 目录，验证每个 115 对象，同步 STRM，扫描 Emby，重新验证规范身份；任何选中集仍然缺失都会导致失败。父补集任务只报告子任务已排队，不会声称转存成功。

## Alternatives considered

拒绝按 provider 优先级静默选择第一个候选，因为这会隐藏多个合理资源。拒绝把整个夸克分享复制到 `_待整理`，因为这会传输无关剧集并丢失 Series 目标保证。拒绝在父任务内直接执行夸克传输，因为单 worker 无法提供独立、可恢复的检查点生命周期。

## Consequences

夸克自动转存需要默认夸克账号和 `quark_autofill_target_id`。选中的夸克文件会保留在夸克。操作者可以看到候选证据、冲突、已排队子任务 ID、字节和文件阶段、取消及保留检查点的重试。父任务完成但存在已排队子任务时不代表补集最终完成；子任务负责 provider、STRM 与 Emby 验证。
