# Agent Note: 规范媒体库整理

Status: implemented

[English](2026-09-09-canonical-media-library-normalization.md) | 中文

## Problem

托管的 115 根目录可以保留 provider 仍认可的文件，但文件夹名称、STRM 路径和 Emby 媒体库可能表达不同分类。仅按路径清理无法安全合并季目录、区分完全重复文件与不同版本、保留蓝光目录结构，也无法在 Emby 条目 ID 变化时迁移用户播放状态。大体积电影还需要单独可见的播放等级，而电视剧追更和综艺追更必须继续成为用户进入 Emby 后最先看到的媒体库。

## Decision

规范流程在修改前冻结完整的 115、STRM、Emby 和非默认用户状态清单。SQLite 计划将每项操作绑定到 115 对象 ID，以及预期父目录 ID、名称、字节大小和 SHA1。执行器先创建目标目录，再处理文件；恢复执行时只接受预期名称或已经计划的目标名称，验证每个完成的目标组，并在 HTTP 405 或 Cookie 失效时停止。已经完成的记录绝不重放。

Provider 根目录继续使用 `emby`。115 直接目录、STRM 目录和 Emby 媒体库使用同一目录表：`电视剧追更`、`综艺追更`、`最新电影`、`电影`、`IMAX巨幕`、`电视剧`、`动漫`、`动漫电影`、`儿童`、`综艺` 和 `纪录片`。两个追更媒体库排在每个用户 Emby 首页的最前面。自动 `合集` 媒体库与源媒体库保持分离。

计划器依次使用 TMDB 身份、媒体类型、测量的文件大小或码率、已验证类型和当前追更状态。`IMAX巨幕` 接收至少 45 GB 或 45 Mbps 的 Movie 文件；该名称表示播放等级，不声称资源属于官方 IMAX 发行。高码率规则之后，现有儿童策展优先于一般动画分类。无法匹配的身份、无效集号、冲突的剧集分配、不受支持的光盘结构和无法绑定的旁车文件会保留为待检查发现。

电影目录使用 `{标题} ({年份}) [tmdbid={id}]`。剧集目录增加 `Season NN`，文件名保留明确的 `SnnEnn` 或多集范围。截断文件名时会为集号、版本和 SHA1 消歧后缀预留空间。与源视频 stem 准确对应的外挂字幕会随视频移动。全量 STRM 同步跳过配置的直接待检查根目录，并识别旧式 AVI、FLV、ISO、RealMedia、VOB 和 WMV 容器。

只有非空 SHA1、字节大小以及 Movie 或 Series／季／集逻辑身份全部一致时，完全重复的视频字节才可合并。保留一个规范对象，其他副本移入 `_待回收`。规范脚本不执行永久删除。残留源目录和有歧义媒体移入 `_待整理`，而配置的每个保留根目录继续位于 provider 根目录。

Emby 切换会在 `/strm-v2` 创建并行媒体库，为每个媒体库和合集媒体库上传一张采用同一系统的 16:9 档案海报，扫描完整替代目录，并验证每个预期 provider 身份、计划内不同版本和集号，包括多集文件表示的每个集号。删除旧媒体库前，切换会立即重新验证替代媒体库 ID、路径、类型和目录内容，且只删除已记录的旧媒体库 ID。用户状态通过 TMDB 加季集号映射；多个旧状态映射到同一逻辑媒体时，已播放和收藏使用逻辑 OR，播放位置和播放次数取最大值，每个不同版本的目标条目都会收到合并后的逻辑状态；已播放 Series 会把每个替代集标记为已播放，因为 Emby 根据子项推导 Series 状态。

## Alternatives considered

**直接根据发布名称重命名路径。** 不采用，因为发布字符串无法证明媒体身份、所属季或重复等价关系，而且中断的纯路径批次无法区分已完成工作与输入变化。

**切换前复制完整媒体根。** 不采用，因为 115 服务端移动能够保留对象身份而不复制媒体全集。冻结前置条件、暂存检查根、并行 STRM 输出和延迟删除 Emby 旧库能够恢复，无需建立第二份 178 TB 媒体树。

**把所有大文件或名称包含 `IMAX` 的文件视为官方 IMAX 媒体。** 不采用，因为文件大小和播放码率表示设备与网络成本，不代表授权放映格式。媒体库海报明确写有 `高码率 · 大文件`。

**整理期间永久删除 SHA1 重复文件。** 不采用，因为错误元数据可能把相同字节分配给不同逻辑剧集。计划器会阻止身份冲突，只把身份一致的重复项暂存起来，等待单独授权的回收操作。

## Consequences

规范过程增加 SQLite 清单和计划 artifact、切换期间的第二个 STRM volume、经过检查的身份 override，以及用户状态迁移步骤。Provider 限流可能要求更新 Cookie，但每个已接受操作都保留在经过验证的组边界。最终目录放弃按发布来源划分，换取稳定媒体身份、清晰播放等级、一级追更媒体库、可恢复的重复项暂存，以及一致的 115、STRM 和 Emby 名称。
